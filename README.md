# HP Pavilion 14 — Product Landing Page

> OIBSIP Level 1, Task 1 · Learning project

A two-page product showcase demonstrating frontend layout, product imagery, navigation and JavaScript interactions.

## Technology

HTML, CSS, JavaScript

## Project structure

`index.html` — landing page; `featues.html` — features page; `style.css` — styling; `main.js` — interactions.

## Run locally

```bash
git clone https://github.com/Manvithagopireddy/OIBSIP-TASK-1.git
cd OIBSIP-TASK-1
```

Open `index.html` in a modern browser. Alternatively, run `python -m http.server 8000` from the project directory and visit http://localhost:8000.

## Review notes

Check navigation, mobile layout and image loading. Product specifications are illustrative; this is not an official HP website.
